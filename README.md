# Mingyang Dai

Electrical Engineering and Computer Science undergraduate at the University of Michigan. I am interested in software, applied AI, embedded systems, signal processing, and engineering research.

## Selected engineering work

### [SpaceKime Research Workbench](https://github.com/my-dai/spacekime-research-demo)

Python research workbench for complex fMRI and time-phase models, including sampling design, identifiability analysis, calibrated reconstruction, uncertainty, PSNR/SSIM, and distribution-level evaluation.

### [Enterprise AI Review Workflow](https://github.com/my-dai/enterprise-ai-review-workflow)

TypeScript and React implementation of review-assistance work I developed for a sponsored engineering project: field-level revisions with apply/undo, library reference matching, duplicate checks, keyword recommendations, and reviewer follow-up. The project integrates with Microsoft Power Platform; this repository runs locally with sample records and adapters.

### [Radiation Weather Station Data Pipeline](https://github.com/my-dai/rws-sensor-data-pipeline)

Python implementation of the acquisition and data architecture I developed for a Raspberry Pi weather and radiation monitoring system: shared sensor schema, validation and unit normalization, partial-failure handling, SQLite persistence, and analysis-ready CSV export.
